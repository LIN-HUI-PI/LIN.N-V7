# NELUUN V9.5 — Authentication API Security Work Plan

Status: **development-only**. No production deployment is authorized.

## Boundaries
- Preserve V9.4, the original V7, and the current Cloudflare production database.
- Work only in `neluun-v9-5-safety`.
- Reuse the existing email one-time-code login and session cookie service; do not create duplicate authentication.
- Add server-verified, short-lived adult access authorizations and tests, separated from account sign-in.
- Prevent child-mode requests from accessing adult protected endpoints; a UI screen lock alone does not provide authorization.
- Keep child AI, billing, and cloud learning synchronization disabled.
- Migrate D1 schema only in an isolated test database after reviewing migration and rollback.

## Validation gate
Automated tests, migration checks, real-device bypass tests, and explicit owner approval are required before any production merge or release.
