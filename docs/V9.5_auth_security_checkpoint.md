## 目前的安全界線

**家長驗證碼發送到已登入帳號的同一個信箱**。這是針對成人區操作的「重新驗證」，不構成獨立的雙因素驗證，也不能證明成年或法定監護人身分。真正的家庭共用裝置保護還需整合本機 PIN、私人資料加密與 UI 防繞過測試。

僅在 `PARENT_STEP_UP_ENABLED=true`、D1 與四個登入 Secrets 俱全時服務才會開啟；未配置則保護端點拒絕。AI、兒童 AI、付款與兒童雲端同步保持關閉。
